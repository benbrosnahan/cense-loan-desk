**P2** · effort M · Testing and maintainability

5. In the app today (http://localhost:3100): click 'Add my first loan', pick the 2026–27 school year, type 1000 in 'What you owe on it today' (the rate fills in as 6.52) and click 'Save loan'. ## Fix

Steps 1 to 6 are green on today's code and can land together. Step 7 lands with the money fixes.
1. Stop stale output. Replace the compile block at verify.mjs:49-54 with
```js
process.chdir(dirname(fileURLToPath(import.meta.url)));
rmSync(".verify", { recursive: true, force: true });
execSync("npx --no-install tsc -p tsconfig.verify.json", { stdio: "inherit" });
```
add `rmSync` to the node:fs import at :59 and `import { fileURLToPath } from "node:url";`, and add tsconfig.verify.json beside tsconfig.json:
```json
{
  "extends": "./tsconfig.json",
  "compilerOptions": { "noEmit": false, "outDir": ".verify", "rootDir": "src",
    "module": "esnext", "moduleResolution": "bundler", "target": "es2020",
    "incremental": false, "isolatedModules": false, "plugins": [] },
  "include": ["src/lib/calc.ts", "src/lib/ranking.ts", "src/lib/utils.ts", "src/lib/storage.ts",
    "src/data/plans.ts", "src/data/seed.ts", "src/types/index.ts"],
  "exclude": []
}
```
