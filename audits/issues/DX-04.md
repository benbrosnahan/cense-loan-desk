## Measured

172 slate-N and 54 navy class uses in src, all green. tailwind.config.ts:15-26 overrides Tailwind's stock slate ramp inside theme.extend, and navy (line 27) is the brand green. Because extend keeps the stock ramps, slate-950 still resolves to stock #020617 (no class uses it today). One colour carries several names: #275B2D is slate-900, navy and brand; #EAF3E7 is slate-100, brand-light, chart-track and selected. Contrast on white, stock slate against the override: slate-800 14.63:1 vs 7.30:1, slate-600 7.58:1 vs 5.79:1, slate-500 4.76:1 vs 4.51:1. On the page colour #FFFCEC the overridden slate-500 is 4.38:1, where stock slate-500 is 4.62:1. README.md:160 records slate-500 on slate-50 at 4.04:1; the stock pair would be 4.55:1. Colour literals outside the config: text-[#8A4213] at ui.tsx:126 (no token exists for it), four hex constants (PayoffRunway.tsx:29-32) and seven inline literals in PayoffRunway.tsx, themeColor at layout.tsx:37, and 15 lines of globals.css. Every literal that has a token still matches it.

## Required

Every colour class name says what it is: no stock Tailwind name is redefined, and a stock class such as text-gray-500 either keeps its stock colour or produces no CSS. Every colour the UI uses is defined in tailwind.config.ts and referenced from components and CSS, not repeated as a literal. Borrowers must see no change: the trial of the stored patch measured 12 runs over 6 states at 2 widths, 2,504 elements and 0 computed-style differences.

## Reproduce

No borrower-visible symptom; these steps show the trap. 1. Open http://localhost:3100 in a fresh private window (no saved loans). 2. Right-click the paragraph under 'Every loan you have, on one screen.' and choose Inspect. Its class is text-slate-700 and its computed colour is rgb(58, 107, 62), the green #3A6B3E from the override, not Tailwind's stock slate-700 #334155. The headline above it (text-slate-900) computes to rgb(39, 91, 45), the same #275B2D that navy and brand use. 3. Open tailwind.config.ts: lines 13-27 put the override inside theme.extend, so the stock ramps stay available and slate-950 is still stock #020617. 4. In a local checkout, give any text on the page background the class text-slate-500: it renders #5C7F5F at 4.38:1 on #FFFCEC, under 4.5:1, where stock slate-500 would be 4.62:1.

Or run its test from `audits/`: `AUDIT_SHOW_KNOWN=1 npx playwright test -g "DX-04"`.

## Fix

Apply the stored patch `audits/fixes/DX-04/tailwind-tokens.patch` (10 files; it dry-runs cleanly on main at 0fa60b6). It replaces Tailwind's palette instead of extending it, renames slate-N to forest-N and navy to brand, adds accent.ink for #8A4213, turns PayoffRunway's hex constants into stroke- and fill- classes, and points globals.css at theme(). The config core:

```ts
import stock from "tailwindcss/colors";
// ...
theme: {
  colors: {
    transparent: "transparent", current: "currentColor", white: "#fff", black: "#000",
    amber: stock.amber, red: stock.red, emerald: stock.emerald,
    forest: { 50: "#F6F3E1", /* 100-800: the old slate values */ 900: "#275B2D" },
    brand: { DEFAULT: "#275B2D", hover: "#1E4623", light: "#EAF3E7", border: "#BFDCB8" },
    accent: { DEFAULT: "#C1652E", hover: "#A8531F", light: "#F7E4D6", ink: "#8A4213" },
    chart: { /* unchanged */ }, page: "#FFFCEC", line: "#DCE7D8", selected: "#EAF3E7",
  },
  // Preflight colours every bare `border` from this; keep stock gray-200.
  borderColor: ({ theme }) => ({ ...theme("colors"), DEFAULT: "#e5e7eb" }),
  extend: { /* fontFamily, fontSize, boxShadow as now */ },
},
```

In globals.css, for example, `border: 3px solid #26602d;` becomes `border: 3px solid theme("colors.chart.green");`. Keep the borderColor line: without it preflight emits border-color: currentColor, and every bare border turned green in the first trial run. Leave themeColor in layout.tsx and the #fff and rgba literals in globals.css as they are. Apply it before the DX-05 dead-code fix and the duplicated-logic fix, because the stored patch stops applying after them; if they land first, redo the rename on the final tree instead (slate-N to forest-N and navy to brand, across src/**/*.tsx).

## Severity

No borrower sees a wrong colour or a contrast failure today: slate-500, the shade that passes 4.5:1 as stock grey but not as this green on the page, colours only a chevron icon and input placeholders on white (4.51:1). The cost falls on the next contributor or coding agent, so this is maintainability; README.md:160 records one earlier contrast failure on these shades, since fixed.
