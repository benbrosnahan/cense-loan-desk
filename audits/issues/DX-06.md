# DX-06: framer-motion installed but unused

**P3** · effort S · Testing and maintainability

framer-motion is still a production dependency although nothing imports it, so every install pulls three unused packages; borrowers download none of it.

| | |
|---|---|
| Who it hurts | No borrower is affected. Every npm install and dependency audit downloads and scans three packages that do nothing, and a reader or scanner sees a production dependency that the README already says is gone. |
| Standard | None. |
| Where | package.json:13 and the matching sentence in README.md:199-200; nothing ships, in any state or viewport. |
| Code | [`package.json:13`](../../package.json#L13), [`README.md:199`](../../README.md#L199) |
| Test | `repo.spec.mjs`: "DX-06 every production dependency is imported by the code" |
| Fix proof | Not attempted: fix proofs were run for P0 and P1 only. |

## Measured

0 imports of framer-motion or motion in src or verify.mjs. In package-lock.json only the root depends on it, and it pulls in motion-dom and motion-utils. npm uninstall framer-motion removes exactly those 3 packages, changes no other version, and takes 43 lines out of package-lock.json. node_modules on disk (du -sk) drops by 10,708 KiB, about 10.5 MiB: 361,184 to 350,476 in one copy and 365,912 to 355,204 in another. Builds with and without it: First Load 125 kB both ways; built in the same directory, all 23 static files are byte-identical once the build ID is normalized; in a separate copy the page chunk was 101,571 bytes both ways and differed only in a module id at two sites. The no-framer build passes the 16-step smoke run and shows 0 style, screenshot or text differences over 12 runs and 2,504 elements. README.md:199-200 already says it can be removed.

## Required

package.json lists only packages the code imports.

## Reproduce

No borrower-visible symptom. 1. `grep -rn framer src verify.mjs` prints nothing. 2. `npx knip` lists framer-motion under Unused dependencies at package.json:13. 3. In a scratch copy of the repo, `npm uninstall framer-motion` prints 'removed 3 packages'; `npm run build` then produces the same 23 static files apart from the build ID.

Or run its test from `audits/`: `AUDIT_SHOW_KNOWN=1 npx playwright test -g "DX-06"`.

## Fix

Run `npm uninstall framer-motion`, which removes package.json:13 and its 43 package-lock lines. Then in README.md drop the sentence that starts mid-line 199 and ends on line 200, keeping the bullet's first two sentences:

```diff
 - Entrance animations are CSS, not framer-motion. A script-driven fade starts content at
-  opacity 0, so a tab opened in the background could look blank. `framer-motion` is no
-  longer imported anywhere and can be removed from `package.json`.
+  opacity 0, so a tab opened in the background could look blank.
```

## Severity

No borrower is affected: built with and without it, all 23 shipped static files are byte-identical apart from the build ID, and no static file mentions it. Only installs and dependency audits pay for it, which is hygiene.

## Verification

Confirmed by 2 of 2 skeptics (P3 review lens, one per filing), each with its own before-and-after builds; both kept P3.
