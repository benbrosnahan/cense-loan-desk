# DX-11: No license field in package.json

**P3** · effort S · Testing and maintainability

package.json has no license field, and neither the site nor the README lists the third-party code that ships, including Apache-2.0 SheetJS xlsx and @swc/helpers; this affects people reusing the code, not borrowers.

## Measured

LICENSE:1 reads 'MIT License' (copyright 2026 Ben Brosnahan at line 3). package.json has no license field and sets "private": true at line 4. README.md has no hits for licen, third-party, Apache, SheetJS or the word MIT. license-checker-rseidelsohn 4.4.2 and 5.0.1 with --production --summary list the project as UNLICENSED ('UNLICENSED: 1'), but "private": true causes that, not the missing field: after npm pkg set license=MIT with private kept the row is still UNLICENSED; with private removed and no field the tool reads 'MIT*' from LICENSE; --excludePrivatePackages drops the row with or without the field (tool source lib/index.js:637 in 5.0.1, :653 in 4.4.2). What ships to the browser, from a scratch build with named modules: next, react, react-dom, scheduler, clsx and tailwind-merge (MIT); SheetJS xlsx (Apache-2.0) in the lazy chunk 2170a4aa.319f5df2f1849a13.js (413,745 bytes, same sha256 live and local); @swc/helpers (Apache-2.0) in the first-load chunks 117 and main. The xlsx chunk has 0 hits for Apache, Copyright, @license, '(C) 20' or sheetjs.com, so its license header does not survive the build. There is no LICENSE or NOTICE file under .next/static and no public/ directory; /LICENSE, /license, /licenses, /third-party-notices, /third-party-licenses.txt and /README.md return 404 on port 3100, and /LICENSE and /third-party-licenses.txt return 404 live. Already fine: all 5 WOFF2 fonts carry a copyright line and scripts.sil.org/OFL in their name tables, and the shipped CSS keeps Tailwind's MIT License banner.

## Required

package.json declares the license LICENSE already grants (MIT), and the third-party code that ships is listed with its licenses where people reading the code look (the README). If the notices should also reach people who load the site, a notices file is served with it. Not legal advice.

## Reproduce

1. Open package.json: there is no "license" key, and "private": true is at line 4. LICENSE line 1 reads 'MIT License'.
2. Search README.md for 'licen', 'Apache', 'SheetJS' or the word MIT: no hits.
3. In Chrome open http://localhost:3100, click 'Look around with example loans', open DevTools on the Network panel, then click 'Download as a spreadsheet' in the 'Keep a copy' card below the loan list (src/app/page.tsx:625-635). The chunk 2170a4aa.319f5df2f1849a13.js, which holds SheetJS xlsx, loads; searching its response for 'Apache' or 'Copyright' finds nothing.
4. Open http://localhost:3100/LICENSE and http://localhost:3100/third-party-licenses.txt: both 404, and both also 404 on https://cense-loan-desk.vercel.app.
5. In a scratch copy, npx license-checker-rseidelsohn --production --summary prints 'UNLICENSED: 1'; after npm pkg set license=MIT it still prints 'UNLICENSED: 1', because "private": true sets that row.

Or run its test from `audits/`: `AUDIT_SHOW_KNOWN=1 npx playwright test -g "DX-11"`.

## Fix

Smallest change, keeping "private": true (it guards against an accidental npm publish).

1. Declare the license LICENSE already grants:
```sh
npm pkg set license=MIT
```
This writes "license": "MIT" into package.json. It will not clear license-checker's UNLICENSED row, which comes from "private": true.

2. Add a short section to README.md, before the closing rule at line 209:
```md
## License

MIT, see LICENSE. The page ships code from Next.js, React, React DOM, scheduler, clsx, tailwind-merge and Tailwind CSS base styles (MIT), SheetJS xlsx and @swc/helpers (Apache-2.0), and the fonts Bricolage Grotesque and Instrument Sans (SIL OFL).
```

3. Only if the notices should reach people who load the site (the README is 404 there), add a static file built from the license files already in node_modules. Next serves it at /third-party-licenses.txt:
```sh
mkdir -p public
for p in next react react-dom scheduler clsx tailwind-merge tailwindcss xlsx @swc/helpers; do
  printf '\n==== %s ====\n' "$p"
  cat node_modules/$p/[Ll][Ii][Cc][Ee][Nn][Ss][Ee]*
done > public/third-party-licenses.txt
```
Static text only: no script, no dependency, nothing sent anywhere. Not legal advice.

## Severity

No borrower is affected and no figure changes; it matters only to someone reusing, scanning or redistributing the code, which is rare for this app. Missing metadata and notices are maintainability and hygiene, and whether the notices are legally required is not settled here.

Confirmed by 1 of 1 skeptic (P3 review lens) for the missing field and the missing notices; the filed scanner cause, fix outcome and test were refuted on two tool versions and are corrected here.
