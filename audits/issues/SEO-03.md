# SEO-03: Title and description miss search intent

**Not filed.** Its only member, seo-title-description-miss-intent, split 1 confirmed to 1 refuted, and the tie-breaker did not confirm it. The refuting standards skeptic found that Google's title-link, snippet and SEO Starter Guide pages set no length limit, do not ask for query terms first, and use a brand-plus-descriptor home-page title as their own example. The 600, 920 and 680px limits were working estimates, and no search-volume, Search Console or results-page data exists, so the keyword-led rewrite is a hypothesis to test once the site is indexed, not a defect. Both skeptics agreed on one small wording point the author can fold into any later title edit: the title says 'every student loan' (src/app/layout.tsx:20) while private loans are out of scope (src/types/index.ts:5).
