## Measured

Example balances ($28,101, all paid out before July 1, 2026), $52,000 income, private sector, 'Pay the least overall', Standard chosen:
- 375x812: the bold 'The cutoff only runs one way.' is at docTop 3759 of 4,907px (paragraph 3744-3893). The recommendation's bottom is at 1635, so the gap is 2,124px, 2.62 screens. With nothing answered the gap is 1,984px.
- Styling: 14px body text with a 600-weight lead-in, at the foot of a dashed card headed '2 plans not open to you'; no amber, no icon, not inside a Notice. The tab shows no amber notice at all in this case (one, 'Watch this one', when the employer is nonprofit).
- 1440x900: docTop 2956 of 3,792px, 1,587px (1.76 screens) below the recommendation, in the same order.
- Other mentions: collapsed, the tab's text contains 'consolidat' once. With the four plan disclosures and 'Two rules worth knowing' all open it contains it three times: this paragraph, the green tone=good notice 'All your loans predate the cutoff', and a non-warning mention in the same-plan rule. IBR's con about the cutoff is also inside a collapsed panel.
- Wording: on this example the sentence says consolidating would close Extended, which the same card lists as already not open (under $30,000), so only three of the four plans it names are open. For a Parent PLUS portfolio it also names IBR, which is already closed.
- Cases: absent for a post-cutoff portfolio (correct); present 2,295px below the recommendation in the nonprofit case, 2,465px for a larger portfolio and 1,419px for Parent PLUS.
- Mitigation: when the 'See your debt-free date' card at the bottom is fully in view, the warning is on the same screen at 375x812 (warning y=118-267, card y=674-804), 390x844 and 1440x900, but not at 320x568.

## Required

An irreversible, portfolio-wide consequence is warned next to the recommendation it would undo, styled as a warning like the app's other cutoff notices, and names only plans that would actually close.

## Reproduce

1. In a fresh browser window at phone size (375x812), open the app and click 'Look around with example loans' (8 loans, $28,101, all paid out before July 1, 2026).
2. Tap Plans. Choose 'Pay the least overall' and 'Private sector', and type 52000 in 'Yearly income, before tax'.
3. In the dark 'Where we would start' box, tap 'Use Standard as my plan'.
4. Scroll down past all four plan cards to the dashed card '2 plans not open to you'. 'The cutoff only runs one way.' and its sentence sit at the foot of that card in plain text, about two and a half screens below the box. The sentence names Extended, which the same card lists as not open.
5. Open 'Two rules worth knowing about multiple loans': the only other mention is the green 'All your loans predate the cutoff' notice.
These steps were re-checked through the example loans on the local build: the same sentence, 2,124px below the box.

Or run its test from `audits/`: `AUDIT_SHOW_KNOWN=1 npx playwright test -g "UX-06"`.

## Fix

Move the sentence into an amber Notice directly under the recommendation, keep its guard, and build the plan list from the plans that are open, so it never names one already closed.

```tsx
// src/components/plans/PlansPanel.tsx, after rapOpen (line 311).
// A new loan or a consolidation would close every plan open now except RAP.
const oneWay = closed.some((p) => p.estimate.id === "tiered_standard");
const wouldClose = open
  .filter((p) => p.estimate.id !== "rap")
  .map((p) => PLAN_META[p.estimate.id].name);
const wouldCloseText =
  wouldClose.length > 1
    ? `${wouldClose.slice(0, -1).join(", ")} and ${wouldClose[wouldClose.length - 1]}`
    : wouldClose[0];

// Directly under the recommendation, after line 383:
{oneWay && wouldClose.length > 0 && (
  <Notice tone="warn" title="Before you consolidate or borrow again">
    The cutoff only runs one way. Taking out a new federal loan, or
    consolidating the ones you have, counts as a loan made after July 1,
    2026. That would open Tiered Standard but close {wouldCloseText} for
    every loan you hold.
  </Notice>
)}

// Delete the paragraph at lines 440-450. In the Tiered Standard entry, after the RAP note (lines 433-435),
// keep a pointer so the entry still does not read like a plan to wait for (calc.ts:296-298):
{p.estimate.id === "tiered_standard" &&
  " Getting it would close the plans you have now, as the warning near the top explains."}
```

On the example ($28,101, with or without income) the Notice reads 'close Standard, Graduated and IBR'. Post-cutoff portfolios still get no Notice, as today, because Tiered Standard is open to them.

## Severity

It affects every borrower whose loans all predate July 1, 2026, on every visit to Plans: anyone who stops at the recommendation or leaves by the Payoff tab never passes the only warning about an irreversible, portfolio-wide step. No figure is wrong and the step itself happens outside the app, so it is a bounded defect, not a wrong eligibility answer.
