# UX-11: Saved records cannot be opened or deleted

**P2** · effort M · UX and UI

Saved records show only a date, a total and a loan count, give no change amount and cannot be opened or deleted one at a time, so a borrower must download the spreadsheet to see what a loan's balance was and clear every record to remove one mistake.

## Measured

At 375x812 with 2 saved records of 8 loans (the second changes one balance from $2,256 to $2,401), after a real tap on Records: each record card shows its date, total and '8 loans on record' and has 0 controls (cardsBtns [0,0]); tapping a card changes nothing. None of the 7 unchanged loans appears on the tab, so their recorded balances can be read only in the downloaded spreadsheet; with one record, or two identical ones, 0 of 8 recorded balances are readable in the app. The change row reads '2024–25 unsubsidized balance $2,256 → $2,401' and '145' appears nowhere on the tab (hasDelta false), while the export's 'What changed' sheet computes Difference 145. The 'Changed since' label is at y=846 and the row at y=874 to 914 (scrollY 259), below the 812px fold, under the GAO paragraph, which keeps 208px of a 517px card on every visit. The Records tab has no delete or clear control; the only removal is 'Clear saved records' on Loans under 'Clear my data', which took 2 records to 0 (Undo restored 2).

## Required

Each record opens in place to show every loan's recorded balance and rate; a balance change states its signed amount (+$145, −$26.50, +$0.30) and is blurred by Hide dollar amounts like other figures; one record can be deleted, with Undo; on a phone the newest change is on the tab's first screen.

## Reproduce

1. Open http://localhost:3100 and click 'Look around with example loans'.
2. Open Records and press 'Save today's snapshot'.
3. Open Loans, expand 'Junior unsubsidized', press Edit, change 'What you owe on it today' from 2,256 to 2,401 and press 'Save changes'.
4. Open Records and press 'Save today's snapshot' again.
5. Each card shows only a date, a total and '8 loans on record'; tapping a card does nothing, and no unchanged loan's balance appears. The change row reads 'Junior unsubsidized balance $2,256 → $2,401' with no '+$145'. On a 375x812 phone that row is below the first screen. No control deletes one record; 'Clear saved records' under Loans > 'Clear my data' deletes them all.

Or run its test from `audits/`: `AUDIT_SHOW_KNOWN=1 npx playwright test -g "UX-11"`.

## Fix

Four small changes in two files; together they keep the first change row on a phone's first screen (measured y=728 to 768 of 812).
1. src/components/history/HistoryPanel.tsx:160-163, the balance branch only (a rate row must not get a dollar amount). The signed change sits in an .amt span so Hide dollar amounts blurs it, and shows cents only when there are cents. Import money and moneyCents from @/lib/utils.
```tsx
<>
  <Money value={d.before} /> →{" "}
  <Money value={d.after} />{" "}
  {d.before !== null && d.after !== null && (
    <strong className="amt">
      {d.after > d.before ? "+" : "−"}
      {Number.isInteger(Number(Math.abs(d.after - d.before).toFixed(2)))
        ? money(Math.abs(d.after - d.before))
        : moneyCents(Math.abs(d.after - d.before))}
    </strong>
  )}
</>
```
2. After the diff block (after line 180, inside the Card), let each record open, with delete inside it. Import Disclosure and add `onDeleteSnapshot: (takenAt: string) => void` to Props (lines 24-28).
```tsx
<Disclosure className="mt-3" summary={`See all ${snap.loans.length} loan${snap.loans.length === 1 ? "" : "s"}`}>
  <ul className="space-y-1.5 text-sm">
    {snap.loans.map((l) => (
      <li key={l.id} className="flex flex-wrap justify-between gap-x-3">
        <span className="font-semibold text-slate-900">{l.nickname}</span>
        <span className="tnum text-slate-800"><Money value={l.balance} /> · {pct(l.rate)}</span>
      </li>
    ))}
  </ul>
  <Button size="sm" variant="ghost" className="mt-3 text-red-800 hover:bg-red-50 hover:text-red-900" onClick={() => onDeleteSnapshot(snap.takenAt)}>
    Delete this record
  </Button>
</Disclosure>
```
3. src/app/page.tsx, next to clearSnapshots (268-272), and pass `onDeleteSnapshot={deleteSnapshot}` to HistoryPanel (828-834):
```tsx
const deleteSnapshot = (takenAt: string) => {
  const before = snapshots;
  setSnapshots((prev) => prev.filter((s) => s.takenAt !== takenAt));
  say("Record deleted", { label: "Undo", run: () => setSnapshots(before) });
};
```
4. Once a record exists, fold the GAO paragraph (HistoryPanel.tsx:58-64) into a Disclosure; the empty state keeps it open:
```tsx
const gao = <p className="mt-2 text-base leading-relaxed text-slate-700">In March 2026 the Government Accountability Office found … when it should not have.</p>;
{sorted.length ? <Disclosure className="mt-1" summary="Why keep a dated record">{gao}</Disclosure> : gao}
```

## Severity

Affects every borrower who keeps two or more records, each time they consult them, for example on a call with a servicer. Nothing shown is wrong and the spreadsheet holds every value, so it is a real but bounded defect and a missed opportunity, not a wrong figure.
